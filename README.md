# Valzxy Tolkit

> Toolkit Python untuk Termux

---

## 📦 Installation

Salin dan jalankan perintah berikut di Termux secara berurutan untuk proses instalasi pertama kali:

```bash
pkg update && pkg upgrade -y
pkg install python3 git rust cloudflared termux-api -y
termux-setup-storage ( jika minta izin ketik y )

cd /sdcard
kalo gak ada sdcard pake ini
cd /storage/emulated/0

git clone https://github.com/valzxyofficial01/toolsvalzxyv2
cd toolsvalzxy
pip install -r requirements.txt
python run.py
```

---

## 🚀 How to Run

Jika sudah pernah melakukan instalasi sebelumnya dan hanya ingin menjalankan kembali **Valzxy Tolkit**, gunakan perintah berikut:

```bash
cd tools
python run.py
```
